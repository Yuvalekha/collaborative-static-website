# 🌿 Green Living Shop

A collaborative static e-commerce website created as a group project to promote and showcase eco-friendly products.

## 📌 Project Overview

Green Living Shop is a simple and user-friendly e-commerce website designed for customers interested in sustainable and environmentally friendly products.

The website allows users to browse eco-friendly products, learn about the store, contact the team, provide feedback, and use a basic shopping cart.

The project was developed collaboratively using HTML, CSS, JavaScript, Git, and GitHub.

🧩 Product Page Functionality

The Product Page uses JavaScript to manage the shopping cart.

When a user selects Add to Cart, the product is added to the cart. If the same product is added again, its quantity increases.

The cart supports:

Add to Cart
Increase quantity
Decrease quantity
Remove product
Clear cart
Automatic cart count
Automatic total calculation

The total is calculated using:

Product Price × Quantity

🔄 Team Git Workflow

The team uses a feature branch workflow:

Create / Switch to Feature Branch
              ↓
         Make Changes
              ↓
          git status
              ↓
          git add .
              ↓
         git commit
              ↓
           git push
              ↓
      Create Pull Request
              ↓
          Code Review
              ↓
      Merge into develop
              ↓
       Pull Latest develop
              ↓
        Test Website

This workflow allows team members to work independently while keeping the shared develop branch organized.
