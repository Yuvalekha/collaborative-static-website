# 🌿 Green Living Shop

A collaborative static e-commerce website created to promote eco-friendly products and sustainable living.

## 📌 Project Overview

Green Living Shop allows users to browse eco-friendly products, learn about the store, contact the team, provide feedback, and use a simple shopping cart.
